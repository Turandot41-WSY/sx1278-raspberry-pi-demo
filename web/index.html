Local reference

Latest valid 64-byte frame
Bytes 0–5: TM header · 6–11: Space Packet header · 12–61: MissionRecord · 62–63: FECF.
ECEF position and velocity are received fields. Latitude, longitude and altitude are derived locally. Model Doppler is a transmitted model value, not measured CFO. Earlier received passes remain on the plots.
