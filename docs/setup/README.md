# Setup guides

[Repository overview](../../README.md) · [Hardware and wiring](../hardware/README.md)

Follow the guide for each computer, then use the shared [antenna experiment](../experiments/README.md).

| Computer | Role in this demo | From zero guide |
|---|---|---|
| Raspberry Pi 5 / Raspberry Pi OS 64-bit | Send with Nano B | [Raspberry Pi](raspberry-pi/README.md) |
| macOS on Apple Silicon or Intel | Receive with Nano A | [macOS](macos/README.md) |
| Windows 10/11 x86-64 | Send with B or receive with A | [Windows](windows/README.md) |

Every guide includes tool installation, public clone, Python environment, serial enumeration, board selection, handshake, build and upload. The Pi guide also covers microSD installation, networking, eduroam and optional Bluetooth. All platforms use the same repository and `sx1278-benchmark` environment.
